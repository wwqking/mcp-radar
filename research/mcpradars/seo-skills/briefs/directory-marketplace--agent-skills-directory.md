# Agent Skills Directory for Claude Code, Codex, Cursor, and More

## Direct answer goal

Within the first 100 words, let visitors search and filter skills by client, task, source, install method, license, and verification status. Explain that listings are discovered from public repositories, but only entries with current install, compatibility, or test evidence earn a “verified” label.
